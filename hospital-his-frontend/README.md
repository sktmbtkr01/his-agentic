# 🏥 Hospital HIS Frontend

The staff and administrative dashboard for the LifelineX Hospital Information System. This interface allows doctors, nurses, and administrators to manage patient records, appointments, inventory, and billing.

## 🚀 Features

- **Staff Dashboard**: Overview of hospital operations.
- **Patient Management**: View and manage patient details and medical history.
- **Appointment Scheduling**: Interface for booking and managing appointments.
- **Billing & Inventory**: Management of hospital resources and finances.
- **Real-time Updates**: Socket.IO integration for live notifications.

## 🛠️ Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **State Management**: Redux Toolkit
- **Routing**: React Router
- **UI Components**: Lucide React Icons, Framer Motion (Animations)

## 📦 Installation

1.  Navigate to the directory:
    ```bash
    cd hospital-his-frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```

## 🌐 Configuration

Ensure the backend server is running on the port specified in your `.env` (default is usually `http://localhost:5001`).
